# Imágenes del Portfolio

## Foto de Perfil

Coloca tu foto de perfil en este directorio con el nombre `profile.jpg` (o actualiza la ruta en `src/config/constants.js`).

### Formatos soportados:
- JPG/JPEG
- PNG
- WebP

### Recomendaciones:
- Tamaño recomendado: 400x400px o superior (cuadrada)
- Formato: JPG con buena calidad
- La imagen se mostrará como un círculo, así que asegúrate de que el sujeto esté centrado

### Ejemplo:
Si tu imagen se llama `mi-foto.jpg`, actualiza en `src/config/constants.js`:
```javascript
profileImage: '/images/mi-foto.jpg',
```
